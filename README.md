# Python-script-collection
A collection of random python scripts that I have made over the years


Normalize.py - A quick and dirty way to normalize parts of a mongoDB database.

brevo_lists.py - A script that allows you to pull all of your Brevo (SendInBlue) Campaigns into an excel document. It includes which lists or segments were used. This is great for marketing teams to easily pull all of their data. Keep in mind that the Brevo API is rate limited so I have slowed the script down so that this can run without having to be monitored. Although all of the campaign data is being pulled from the API, only the Campaign ID and Name are being written to the file. You can change this if you want.
